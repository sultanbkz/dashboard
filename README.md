# Своя сквозная аналитика (Facebook + amoCRM)

Свой аналог Comboards. Бэкенд сам ходит в Facebook и amoCRM, сливает данные по ad_id
и считает метрики. Фронтенд показывает воронку, каналы и креативы. Живёт по ссылке.

## Как устроено
- lib/facebook.js   тянет объявления из Facebook Marketing API
- lib/amocrm.js     тянет сделки из amoCRM API
- api/data.js       сливает их по ad_id и считает CPL, цену квала, CPO, ROAS, ROMI, AOV
- public/index.html дашборд, читает /api/data

## Что нужно от тебя
Два токена. Без них приложение не подключится, взять их за тебя нельзя.

### 1. Токен Facebook (ads_read)
- Заходишь на developers.facebook.com, создаёшь приложение типа Business.
- В инструменте Graph API Explorer или в разделе Marketing API получаешь токен с правом ads_read.
- Лучше сразу оформить долгоживущий токен, обычные живут пару часов.
- Узнаёшь ID рекламных кабинетов (цифры без слова act).

### 2. Токен amoCRM
- В amoCRM: Настройки, Интеграции, создаёшь свою интеграцию.
- Берёшь долгоживущий токен доступа.
- Находишь id поля сделки, куда падает ad_id (метка креатива).
- Находишь id этапов, которые считаются квалом, и id этапа продажи.

## Настройка (переменные окружения)
Скопируй .env.example в настройки проекта на хостинге и заполни:

    FB_TOKEN=...
    FB_AD_ACCOUNTS=2592061201241372,648859043070419
    AMO_SUBDOMAIN=твой_поддомен
    AMO_TOKEN=...
    AMO_ADID_FIELD_ID=...
    AMO_QUAL_STATUS_IDS=...,...
    AMO_WON_STATUS_ID=142

## Деплой на Vercel
1. Залей папку в репозиторий GitHub.
2. На vercel.com импортируй репозиторий.
3. В Settings, Environment Variables впиши все переменные из .env.example.
4. Deploy. Получишь ссылку вида имя.vercel.app.
5. Открываешь ссылку, дашборд сам тянет данные и обновляется.

## Порядок сборки, по шагам
Не подключай всё сразу. Сначала Facebook, потом amoCRM.
1. Задай только FB переменные, задеплой, проверь, что в /api/data приходит расход по объявлениям.
2. Добавь amoCRM переменные, проверь, что появились лиды, квал, продажи и выручка.
3. Настрой этапы квала и продажи, сверь цифры с amoCRM.

## Важное
- Токены это секреты. Держи их только в переменных окружения, не в коде и не в публичном репозитории.
- Долгоживущие токены всё равно истекают. Раз в период их нужно обновлять, либо добавить авто-обновление, это следующий шаг.
- Матчинг по креативу работает, только если ad_id реально доезжает до сделки в amoCRM. У тебя это уже настроено.
